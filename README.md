# Coadă de comenzi

Coadă implementată cu listă simplu înlănțuită, cu comenzi ale clienților.

## Funcționalități

- inserarea comenzilor la sfârșitul cozii
- traversarea cozii
- extragerea comenzilor de la începutul cozii
- salvarea comenzilor într-un vector
- dezalocarea memoriei

## Structura de date

`Comanda`: cod, nume client, număr de produse, suma de plată.

## Rulare

Se deschide `Coada.sln` în Visual Studio.
